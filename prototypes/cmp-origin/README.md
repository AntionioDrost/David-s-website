# CMP Origin

CMP Origin is the Wix-aligned ComplyMyProperty prototype direction. It is a self-contained static prototype built inside `prototypes/cmp-origin/`.

## Purpose

Show Nick what the original ComplyMyProperty website could become if the current Wix direction were completed as a working landlord journey.

## Scope

- Homepage matching the current ComplyMyProperty direction.
- Services hub with the broad service catalogue.
- Reusable service-page template.
- Check-property flow with generated address choices.
- My Properties view.
- Simple property dashboard/workspace.
- Static document upload, smart tools and human support panel.
- Careful possession and eviction preparation copy.

## Boundaries

- No live address API.
- No live document upload.
- No backend.
- No payment or booking backend.
- No deployment.
- No hotlinked Wix assets.
- No changes to CMP Prime, Vault, Concierge, Radar or old root CMP files.
