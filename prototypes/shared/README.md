# CMP Prototype Shared Folder

This folder is reserved for future neutral shared assets or helpers that are safe for all three CMP prototypes.

## Allowed Later

- Shared product rules that apply equally to all prototypes.
- Neutral test helpers that do not define visual direction.
- Neutral data adapters with no private keys.
- Shared fixture-free type definitions if a later build uses a typed stack.

## Not Allowed

- Old root-level CMP UI.
- Old CMP journey code.
- Rescue prototype code.
- Brand-specific styles for CMP Prime, CMP Vault, or CMP Concierge.
- Private API keys or tokens.
- Screenshot or audit outputs from old CMP work.

Any shared code added later must preserve brand separation and must not make the prototypes feel like the same interface with different colours.
