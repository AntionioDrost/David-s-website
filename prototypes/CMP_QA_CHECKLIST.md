# CMP QA Checklist

Run this checklist after a prototype has been built and before any folder-only draft deploy.

- [ ] no old terminology visible;
- [ ] one Add Property path;
- [ ] one postcode input;
- [ ] one Smart Checks step;
- [ ] one found-data review;
- [ ] one next action;
- [ ] evidence state updates after fake upload;
- [ ] service request state updates after draft request;
- [ ] monitoring updates after evidence/service change;
- [ ] Ask CMP contextual only;
- [ ] My Properties works;
- [ ] mobile works;
- [ ] no invisible text;
- [ ] no horizontal overflow;
- [ ] unique logo;
- [ ] unique colour scheme;
- [ ] Netlify preview folder-only deploy.

## Setup Pass Note

This checklist is for future prototype builds. This setup pass does not create screenshots, audits, tests, HTML, CSS, JavaScript, or Netlify deploys.
